## Controls Summary

By default you will be able to see the Home folder of your server. You can click other folders to view their contents. On the top left corner you can see your current path.
![DuckPanel File Manager showing the current server path and files](/using_the_panel/file_manager_controls/1.png)

### Without selecting any files you can:

- Open the Recycle Bin to retrieve previously deleted files (up to 24h)
- Download files from a link (if the link directly leads to a file!)
- Create new directories or files
- Upload files directly from your computer
- Select all files with the checkbox in the top left corner.

You can also select individual files by clicking the checkbox to the left of the filename.

### While having file(s) selected you can:

- Copy or move the file within the current server's directories or even to <u>other split servers</u>!
- Archive files/folder into a single compressed file. Selecting this option will create a file ending in `.tar.gz` with a name based either on the single file you archived, or the date and time if you selected multiple.
- Unarchive is available for compressed files.
- Restore which allows you to "Quick Restore" a file or directory as explained in our [Managing Backups guide](/backups).
- Download which allows you to either download a single file as is, or a group of files (or folder) as a `.tar.gz`.
- Delete files. By default, this will send files to the Recycle Bin (space permitting) for 24 hours or until manually purged.


### You can also click `...` next to a file for additional options. Here you can also:

- All the options mentioned before.
- Rename a file/folder.
- Manage system permissions.
- Pin the file to the top of home directory regardless of location.

## Moving Files

With DuckPanel you can easily move files from one nested directory to a different directory under "Home", and any other combination both on the same server and other servers in the same plan (same server split group).

![DuckPanel File Manager File Move](/using_the_panel/file_manager_controls/4.gif)

### Moving Files via Drag & Drop

Additionally you can easily drag and drop files to move within the same directory structure. You can even move the file "up" to its parent directory by dragging over the upward arrow, in our example it would be over "Back to Home".

You can also drag the file directly to the Recycle Bin to delete it if you are on the Home directoy. If you deeply nested within multiple directory, you can also drag and drop files to a higher directory by dragging it into the relevant folder via the "breadcrumbs" (or "/home/plugins/worldedit/etc" as an example of how breadcrumbs look) above the file list. 

Drag and drop only works for moving files within the same server. Moving to a split requires the use of the "Copy" or "Move" options mentioned previously. 

![DuckPanel File Manager File Move](/using_the_panel/file_manager_controls/5.gif)

## Uploading Files (Without SFTP)

Our panel supports "drag & drop" uploads for single files, multiple files, and multiple directories. The process is just as simple as using traditional SFTP methods. You can see a short showcase of the features below:

![DuckPanel File Manager Multifile Upload](/using_the_panel/file_manager_controls/3.gif)

While uploading files you can pause, resume, retry, and cancel the process as needed. You can also minimize or expand the window. By default the upload window will be minimized and be left as a widget at the bottom right corner of the screen once the upload is completed.

If you cancel the upload by refreshing or closing the website, you can resume it by simply trying to upload the same exact set of files within the next 72 hours. When uploading overwrite allows you to skip existing files.

Some older browser builds found in outdated PCs or phones might struggle to feature the upload option correctly, if this is the case, please try a modern browser instead.

## Downloading Files

Our panel supports both file and folder downloads. You can download several files and/or folders at the same time, by simply selecting the group you wish to download by marking their checkbox, and then clicking the download button at the bottom middle submenu as shown in our example below. Currently you can only download up to 100 Files/Directories at once.

For single file downloads you can simply right click the file and select the "Download" option to download it. 

![DuckPanel File Manager Multifile Download](/using_the_panel/file_manager_controls/2.png)

If you download multiple files (or a directory) they'll be shown as a tar.gz file in your PC's Download directory. In Windows 11 you can simply right click the file and select "Extract All". For other OSs you might need to extract the file twice, once to turn it into a .tar and then again to create the final directory.

## Download From URL

Download From URL is a DuckPanel feature that allows users to download to their server any file(s) that's provided by a directly downloadable link. While this will work for a large subset of download URLs you might encounter, it will not be the right tool for most, as usually download URLs are not direct. If the process fails, and you are sure that the URL was pasted in correctly, without any spaces, you can check out the error ir provided; while "pulls already running", and "disk limit reached" can be fixed by either waiting or clearing up space, most other errors will point to a link that doesn't work with our system.

The example below shows the feature being used with a backup URL from another Bloom server from a different plan. You can get this specific link by going to the "Backups" tab and clicking the "..." menu next to the backup of interest and selecting "Copy Link". 

:::warning Backup URLs
This particular URL is no longer available as it was an example, however, you should never share a Backup URL with anyone has that will give them direct access to the backup. The link expires after 15 minutes, and you must accept the risk of producing it before proceeding by clicking "I understand" when prompted.
:::
