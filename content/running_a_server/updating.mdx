## How to update or change version

Go to the [panel](https://panel.atbphosting.com), select your server and open the **Settings** tab. There you will find the **Change Server Type** box. Read the precautions below before you continue.

## Precautions

<Callout type="warning">

Before updating or changing Minecraft versions, create and test a backup of your entire server. You can upgrade Minecraft servers, but you can't go back to a previous version unless you reset your worlds or restore a backup that was made when the server was on the previous version. Downgrading a world without causing corruption is near impossible.

</Callout>

If you aren't using our completely free and automatic backup feature yet, we highly suggest you set it up before updating.

## Updating or changing versions and jars through the panel

After you have selected the server type, you will be able to see the available versions of Minecraft and builds. Here you can also select the type of server you want to run: Vanilla, Paper, Forge and others.

After this, you can click on the version you want to change to. For example, to upgrade your server to Paper 1.21.8, click the version 1.21.8 and the install panel will pop up. Don't forget to click the button to accept the EULA, then click install.

You can also click the "Change Server Type" button to change the jar, version or build your server runs on. Make sure to hit "Reinstall now" if you want the upgrade to proceed.

<Callout type="warning">

Only click the "Wipe Server Files" button if you want to wipe your server files. Changing to a different egg or server type with wipe on deletes **everything**, including worlds and plugins. Download a backup first.

</Callout>

Pick an exact version number rather than "latest". With "latest", a later reinstall can quietly upgrade your server to a new Minecraft version that your plugins do not support yet.

Changing version can also need a different Java version. If the server will not start after a change, see [Change Java Version](/running_a_server/java-version).

After you have followed the steps above, you can run your server and test out your new version.

You can periodically check the **Settings** tab, and you will see a **New build available! We recommend to update to the latest build.** message if a new build of the server jar is available.

## Updating the server manually

- [Create a full backup](/using_the_panel/backups/guide) of your server. As an additional step, we suggest testing this backup on a local or a split test server.
- Remove your current server jar through [SFTP](/using_the_panel/sftp) or the [File Manager](/using_the_panel/file-manager-controls).
- Download the new version of your server software. If you are unsure which one to use, check out our guide on server jars [here](/running_a_server/jars).
- Upload it using SFTP or the File Manager and make sure to define the full name (such as `paper-1.18-023`) in the 'Startup' tab on the panel.

## After a new Minecraft release

Right after a new Minecraft release many plugins and mods are not ready. Stay on the previous version until your plugins say they support the new one, and make a backup first. Run `ver` in the console to see which version you are on. Going back is only safe with a backup made before the upgrade: a world that was already opened on the newer version may not load on the older one. Never set a played world back to an older version to "undo" an update; restore the backup from before the upgrade instead.
